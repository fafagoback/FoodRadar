# FR 固定 15 台爬蟲工作機與自適應並行

- 統一掃描後依既有歷史實際爬取耗時（缺值沿用原本估算）由重至輕分派給當下預估負載最小的工作機。固定 15 個唯一所有權分區，不再拆成 34～256 個 GitHub jobs。每家店只分派一次；小型測試中沒有店家的工作機直接回報空成果。
- 每台 GitHub-hosted runner 僅初始化一次，完成所屬全部店家後才結束。每台工作機在整次工作過程中調整整店執行緒（1–12），保留原有 API 間隔、429 Retry-After、降速與原頁重試。每個滿載觀察視窗至少 15 秒與 12 次成功請求；任務尾端樣本不納入。
- 全部 15 台共用 Repo 中的初始執行緒數，各自回報最佳穩定值；依原有條件計算有效報告的算術平均、四捨五入，僅不同時寫入 crawler-state/crawl-settings.json。清除 Actions 不影響設定。
- 第 16 台沿用當次 discovery SHA-256、所有權、RUN、來源 commit、HTTP body SHA-256 與既有店家隔離規則，驗證後更新資料庫，再部署網站。只有工作機未成功上傳成果才重派；已保存成果不重抓。沒有跨機移交執行中店家的機制。
- 整店抓取使用執行緒本機 HTTPS 連線池，每次店家建立新的 Session、Cookie jar；獨立促銷覆核不共用 Session 或連線池。未變更原始 HF 格式、資料庫儲存、價格規則或網站邏輯。不使用新的外部服務。

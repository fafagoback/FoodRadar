# FR 固定15台共用任務池

- 正式爬蟲不使用歷史耗時、商品數或固定店家分區。單一座標只探索一次，固定15台工作機共同領取店家。各機只領取目前空閒的執行緒數，完成並保存後再領取下一個。
- 使用本次 RUN 專用的 GitHub 暫時分支及多個獨立同步鎖，以 Git fast-forward 原子更新任務狀態。這些同步鎖不是工作機分區，任何工作機皆可領取任何店家。競爭失敗須重新讀取，不得覆寫別人的任務。未增加外部服務。
- 租約180秒，每30秒續約。過期時先核對已保存的 Artifact；未保存的才重新放回任務池。過期舊 token 不得覆寫新成果。逐店成果使用不可變 Artifact，原始 HTTP SHA-256 核對後才完成。
- 第16台核對原始探索清單、完成狀態、原始 HTTP SHA-256、每家店唯一結果，再組裝既有 HF Raw 格式；不改資料庫、價格規則或 Pages 部署契約。每台有效執行緒最佳值仍平均寫入既有 crawler-state 分支。
- 工作機或 API 無法取得完整店家，不得當成成功資料。保留既有有限隔離規則，未完成的任務不部署。動態店家領取不等於大型店家跨機分類或逐頁中途恢復。
- Artifact API 每個工作機有數量上限；大量店家與 Git 原子更新效能必須以真實測試驗收，不能直接宣稱全台規模已驗證。

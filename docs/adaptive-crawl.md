# 自適應爬蟲階段一

- 同一次 RUN 內每台工作機自行調整整店執行緒數量（1–12）。保留共享的正常 API 速率與原有逐頁重試。
- 30 秒有效滿載視窗、至少 20 次成功請求才納入學習。限流立即減半，待冷卻及原速率恢復才繼續探測；增加無收益時回到較少執行緒。
- 15 台各自輸出最佳穩定值；第 16 台在更新成功後取有效樣本算術平均、四捨五入，僅數值改變時更新 crawler-state 分支的 crawl-settings.json。
- 不使用 Supabase，不修改 HF Raw 格式，不新增付費服務。
- 此階段仍採固定跨機分工；跨機動態租約與可恢復分頁檢查點未完成。現有單頁重試用盡仍會按原有失敗規則處理。
